# Dashboard Design Guide

## Recommended Page Structure

### Page 1 — Executive Overview
- Revenue
- Orders
- Customers
- AOV
- Growth
- Main trend
- Top categories
- AI summary

### Page 2 — Customer Analytics
- New vs repeat
- Segment performance
- Retention
- Customer contribution
- Drill-through

### Page 3 — Product / Category Analytics
- Category revenue
- Volume
- Margin if available
- Top / bottom products
- Trend

### Page 4 — AI Insights
- What happened?
- Why?
- What should we do?
- Evidence / source
- Confidence / limitations

## Design Rules

- Use one primary visual hierarchy.
- Keep KPI cards compact and comparable.
- Avoid chart overload.
- Use meaningful titles, not generic labels.
- Keep filters grouped in one area.
- Display date range and data freshness.
- Use consistent number formatting.
- Always validate dashboard values against the source dataset.
