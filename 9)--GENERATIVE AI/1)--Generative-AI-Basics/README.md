# 01--Generative-AI-Basics

This folder introduces the fundamental concepts required to understand Generative AI before moving to LLMs, Prompt Engineering, Embeddings, Vector Databases, RAG, LangChain, and LangGraph.

## Learning Flow

1. What is Generative AI?
2. Traditional AI vs Generative AI
3. AI → ML → Deep Learning → Generative AI
4. Foundation Models
5. Tokens, Context Window, Temperature and Parameters
6. Common Generative AI Use Cases
7. Basic LLM workflow
8. Responsible and practical use of Generative AI

## Files

- `01_What_Is_Generative_AI.py` — core definition and examples
- `02_AI_ML_DL_GenAI_Comparison.py` — relationship between AI, ML, DL and GenAI
- `03_Foundation_Models.py` — foundation model concepts
- `04_Tokens_Context_Temperature.py` — essential LLM terminology
- `05_Generative_AI_Use_Cases.py` — practical industry use cases
- `06_Basic_LLM_Workflow.py` — conceptual end-to-end LLM workflow
- `Generative_AI_Basics.ipynb` — structured notebook for learning and practice

- Basic Machine Learning concepts
- Basic Deep Learning concepts
