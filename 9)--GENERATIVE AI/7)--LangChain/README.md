# 07--LangChain

## LangChain — LLM Application Development Framework

This folder teaches **LangChain** from core concepts to composable workflows, retrieval, tools, agents, structured output, RAG integration, and production practices.

## Learning Flow

1. What is LangChain
2. Core concepts
3. Architecture
4. Chat models
5. Prompt templates
6. Message types
7. Output parsers
8. Runnables and LCEL
9. Chains
10. Sequential workflows
11. Retrievers
12. Document loaders
13. Text splitters
14. Embeddings and vector stores
15. Retrieval chains
16. Tools and tool calling
17. Agents
18. Agent workflow
19. Memory and conversation state
20. Structured output
21. LangChain + RAG integration
22. Production practices
23. Mini LangChain-style application
24. Real LangChain setup reference

## Important

The first examples are intentionally dependency-light so the framework concepts are clear before using provider-specific APIs.

`24_Real_LangChain_Setup_Reference.py` contains a real setup reference. Replace `YOUR_MODEL_NAME` with a model supported by your configured provider and keep API keys in environment variables.
