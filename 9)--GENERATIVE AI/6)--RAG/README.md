# 06--RAG

This folder teaches **RAG (Retrieval-Augmented Generation)** from fundamentals to a practical end-to-end pipeline.

3. RAG architecture
4. Document ingestion
5. Text chunking
6. Chunking strategies
7. Embeddings in RAG
8. Vector store
9. Query processing
10. Similarity retrieval
11. Top-K retrieval
12. Metadata filtering
13. Hybrid search
14. Reranking
15. Context construction
16. RAG prompt templates
17. Grounded generation
18. Citations and source attribution
19. RAG evaluation
20. Common RAG failures
21. Advanced RAG patterns
22. Production considerations
23. Mini RAG pipeline

### Important

The Python examples are intentionally dependency-light and focus on understanding the RAG mechanics before using frameworks such as LangChain or LlamaIndex.
